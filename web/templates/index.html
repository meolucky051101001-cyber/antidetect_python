Lịch Tự Động

Lịch chạy khi server đang mở; lỡ giờ trong vòng 60 phút (do restart) vẫn tự chạy bù một lần. Profile scope: tất cả (chọn riêng qua API).

API Token cho Automation

Token dùng làm Authorization: Bearer <token> cho REST API — không đổi khi server khởi động lại (khác access key). Chỉ lưu hash trên máy; plaintext chỉ hiển thị lúc tạo.
