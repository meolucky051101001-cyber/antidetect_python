**Fingerprint revision 2 — behavioral contract and migration**

Revision 2 is an explicit configuration change. Existing profiles deserialize as revision 1; newly generated profiles select revision 2. Existing seeds, profile IDs, browser pins and mode choices are not rewritten by the renderer.

Revision 2 treats the numeric seed 0 as a valid, distinct seed; revision 1 retains its historical zero-to-default fallback. The corrected canvas pipeline applies deterministic readout changes only to fully opaque pixels in supported sRGB/unorm8 2D canvases. Coordinates are absolute: full reads, tiled reads and negative-sized crops address the same pixels. HTML canvas and OffscreenCanvas use the same implementation. Export creates a snapshot and never writes back to the source, including while callbacks or Promises are pending.

Native fallback is deliberate for WebGL pixels/metadata, WebGPU, audio, fonts, media devices, ClientRects and speech in revision 2. Their values remain properties of the host browser/device and can link profiles on the same machine. Unique revision 2 provides supported canvas-2D readout separation; it does not make every profile a different physical device. Display-P3/float16 canvas and object-valued coordinate arguments retain native pixels and are reported by get_stealth_capabilities. JavaScript hooks are not an undetectability guarantee.

Revision 1 remains explicit legacy behavior with known crop/API inconsistencies. The source-mutation fix applies to both revisions; snapshot export, removal of global markers and removal of Blob worker wrapping may change old export output. Keeping a seed does not preserve the hashes of a defective algorithm. Strict operation must not certify revision 1 as fully consistent. Production migration requires a separate decision; this change uses only synthetic profiles.

The CDP launcher is the sole injection owner. Page pre-document scripts and paused worker targets must install before user code and only once per context. Payloads no longer set __adStealth, __adWorkerStealth or __adWorkerBase, patch iframe contentWindow to inject again, or replace Worker constructors with Blob wrappers. Dedicated/shared/service worker coverage must be verified by the live fixture, not inferred from target-type strings.

Behavior tests:
- test_stealth_behavior.py runs real rendered payloads in synthetic Web API realms. It checks source immutability, read consistency, offsets/errors, native object contracts and policy reporting.
- test_live_fingerprint_contracts.py is opt-in via ANTIDETECT_RUN_LIVE_FINGERPRINT=1. It invokes tools/fingerprint_contract_probe.py with a newly created TEMP dataset and localhost fixtures.
- The browser fixture compares native Chrome with BrowserLauncher Unique/Authentic, decodes exported PNG using the clean comparator, checks same/cross-origin frames, a cross-site localhost-versus-127.0.0.1 OOPIF with an observed iframe target type, Offscreen, dedicated/module/nested/shared/service worker paths and restarts. Worker sources also read an opaque fixture canvas at their first statement, so late installation before a subsequent message cannot pass as early installation. Product pages and the OOPIF are observed through direct page/iframe CDP sockets pinned to the original literal loopback host and port with environment proxies disabled; the probe never sets auto-attach or resumes worker targets. Playwright is used only for the independent clean comparator because its normal CDP connection would compete with the product controller and resume service workers early. It records source-file hashes because a worktree may have uncommitted changes.
- A separate negative strict-verification fixture injects a failed verifier and requires CONFIGURATION_UNVERIFIED, navigation_allowed=false, zero requests to the localhost target endpoint, and confirmed browser cleanup. Its result is recorded separately from canvas coverage.
- ANTIDETECT_LIVE_FINGERPRINT_REPORT optionally retains the sanitized report outside pytest's temporary retention tree. It contains only synthetic checks, environment/build information and hashes, never cookie/session contents.
- tools/verify_live.py now checks the selected canvas revision. Native GPU observations are no longer compared against a different machine's hard-coded limits or an unapplied profile renderer; absence of that comparison is reported.

Passing this fixture is evidence for the tested browser/build/GPU and local workload. It does not certify all browser builds, every graphics pixel format, every proxy path, external detector outcomes, or production account safety.

The expanded local fixture passed on Chrome 157.0.8103.51 / Windows / Intel ANGLE with 12 realms in each of Unique and Authentic, a Unique restart, first-statement worker observations, and the negative strict-verification gate. Both mode runs ended with healthy CDP status and successful cleanup. This is one tested browser/build/device combination; the build/device matrix and longer soak remain separate release gates.
